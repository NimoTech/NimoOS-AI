## Wiki keeper

Read + append to the user's personal wiki via the existing wiki tools.

### When to use
- User wants to look up something they've previously noted
- User wants to add a new entry under a path

### How to run
- Use `wiki_get_node` to read a path
- Use `wiki_list_full_tree` to navigate
- Use `wiki_append_user_notes` to append
- Always confirm before writing
